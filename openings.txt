# Named Othello openings. One opening per line: Name|space-separated moves
# (lowercase algebraic, e.g. "f5 d6 c3 d3 c4"). Loaded fresh at every
# program start (see openings.cpp) — edit this file directly to add,
# correct, or extend openings; nothing needs recompiling or regenerating.
#
# Sources:
#   - Robert Gatliff's opening catalogue (July 1995), fetched directly from
#     https://www.othello.nl/content/anim/openings.txt, cross-checked
#     against https://reversiboardgame.com/openings/ and
#     https://www.ultraboardgames.com/othello/opening-moves.php (both
#     digitize the same catalogue) — the bulk of this file.
#   - A handful of additional openings independently corroborated by
#     https://samsoft.org.uk/reversi/openings.htm (a separate compilation
#     that isn't just a re-digitization of Gatliff's list): Aubrey
#     (Feldborg Continuation), Central Rose-Bill, F.A.T. Draw, Lysons,
#     Rocket. (samsoft's "Bent Ganglion" was checked and turned out to be
#     the exact same board position as Gatliff's "Ganglion" — the two
#     sources just use different names for it; see the HKOA tie-break note
#     below for which name this file actually uses.)
#   - Deliberately NOT included: the ~500-name extended catalogue at
#     berg.earthlingz.de/ocd (data/openings1/openings.txt) — checked, but
#     its names beyond Gatliff's ~71 (e.g. "Central Tiger", "Triangle",
#     "Warsaw Triangle", "Caspard", "Ladybird") don't show up on samsoft.org.uk
#     or any other independent source checked, i.e. they're only findable in
#     that one compilation. Per the project's own policy of only including
#     well-corroborated, popular openings (not everything a single source
#     happens to list), those were left out.
#   - The "Parallel" family has exactly one named line ("f5 f4" itself) in
#     every multi-source-corroborated catalogue checked (Gatliff, the
#     ~500-name extended catalogue) — Parallel really is that thin in the
#     mainstream literature, not a gap in this file.
#   - Four openings from https://www.othello.hk/opening-list/ (Hong Kong
#     Othello Association): Mouse, Rotated Raccoon Dog, Rotated Snake,
#     Wild Rabbit. None of these four appear in any other source checked
#     (the other 13 named entries on HKOA's page all turned out to exactly
#     match openings already in this file, which is good cross-validation
#     of the file overall) — kept anyway as a deliberate exception to the
#     usual multi-source bar, on the basis that an official national
#     association's own catalogue is reasonable authority even standing
#     alone. Not a precedent for silently relaxing the bar elsewhere; each
#     addition here was still checked individually.
#   - HKOA (https://www.othello.hk/opening-list/) is treated as the
#     tie-breaking source of truth for naming: if a position already in
#     this file is ever found under a conflicting name on HKOA's page, use
#     HKOA's name. (Checked at the time of adding the above: none of the
#     13 overlapping HKOA entries actually conflicted with this file's
#     existing names — e.g. HKOA's "Snake / Peasant" and "Heath /
#     Tobidashi" both still list this file's name, Snake/Heath, first.
#     One conflict was missed at the time because it was a name-string
#     match, not a position match: HKOA lists "Ganglion"'s exact position
#     (f5 d6 c3 g5, moves c4e3f6b4 in HKOA's own notation) as "Bent
#     Ganglion" — found later when an app using HKOA's naming displayed
#     it that way. Renamed to "Bent Ganglion" per the tie-break policy.)
#
# Only one symmetric variant of each opening is kept here (starting move
# may be c4, d3, e6, or f5 depending on which the source used) since the
# game canonicalizes positions across all 8 board symmetries at load time —
# the other 3 equivalent first moves and any mirror-image continuation
# resolve to the same entry automatically.
#
# Blank lines and lines starting with # are ignored.
